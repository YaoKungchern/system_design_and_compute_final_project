2024.6.17
V5.1.5	1. 增加一个驱动掉电辨识的标志位，上电后默认一直是true，用户可修改为false，驱动掉电重新上电，标志恢复为true，用户可知道发生过掉电情况。
		修改指令：地址 + 0x50 + 掉电辨识标志位状态(0 or 1) + 校验字节(0x6B)
		读取方法：发送读取状态标志位指令，地址 + 0x3A + 校验字节(0x6B)，返回的数据 & 0x80，如果为0就是false，不为0则为true。	
	2. 增加P_Pul菜单复用为ESI_RCO（将En脚复用为回零限位和Dir脚复用为到位输出）时，Stp脚复用为报警输出（出现堵转/欠压等异常输出低电平0V）。
	3. 堵转功能Clog_Pro菜单增加一个AutoZero选项，作用是，当触发堵转后，不关闭电机，而是像无限位碰撞回零一样，复位为零点，让电机保持有力。
	4. 增加左右限位功能，碰到左限位后，电机不能再向左跑，碰到右限位后，电机不能再向右跑，具体设置方法如下：
		1) 通讯控制：P_Pul设置为LR_ESI，将En脚复用为负角度限位开关输入，Dir脚为到位输出高电平，Stp脚为正角度限位开关输入；
		2) 脉冲控制：P_Serial设置为LR_ESI，将R/A/H脚复用为负角度限位开关输入，T/B/L脚为正角度限位开关输入；
		3) 左右限位触发按下后，速度模式和位置模式会返回两个限位的状态，比如：
			如果左右限位都没按下，发送位置模式指令后，返回：地址 + 0xFD + 0x02 + 校验字节(0x6B)
			如果左限位按下，发送位置模式指令后，返回：地址 + 0xFD + 0x12 + 校验字节(0x6B)
			如果右限位按下，发送位置模式指令后，返回：地址 + 0xFD + 0x22 + 校验字节(0x6B)
			如果左右限位都按下，发送位置模式指令后，返回：地址 + 0xFD + 0x32 + 校验字节(0x6B)
	5. 报警输出改为输出低电平(0V)，为3D打印机/雕刻机用本驱动实现无限位回零提供一个可能。
