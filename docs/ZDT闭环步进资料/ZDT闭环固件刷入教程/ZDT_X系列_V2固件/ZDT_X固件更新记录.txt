2025.4.28
V2.0.4	1. 增加左右限位功能，碰到左限位后，电机不能再向左跑，碰到右限位后，电机不能再向右跑，具体设置方法如下：
		1) 通讯控制：P_Pul设置为LR_ESI，将En脚复用为负角度限位开关输入，Dir脚为到位输出高电平，Stp脚为正角度限位开关输入；
		2) 脉冲控制：P_Serial设置为LR_ESI，将R/A/H脚复用为负角度限位开关输入，T/B/L脚为正角度限位开关输入；
		3) 左右限位触发按下后，速度模式和位置模式会返回两个限位的状态，比如：
			如果左右限位都没按下，发送位置模式指令后，返回：地址 + 0xFD + 0x02 + 校验字节(0x6B)
			如果左限位按下，发送位置模式指令后，返回：地址 + 0xFD + 0x12 + 校验字节(0x6B)
			如果右限位按下，发送位置模式指令后，返回：地址 + 0xFD + 0x22 + 校验字节(0x6B)
			如果左右限位都按下，发送位置模式指令后，返回：地址 + 0xFD + 0x32 + 校验字节(0x6B)
	2. 将默认位置到达窗口值从0.3°调整为0.8°(开启到位返回后，到达目标位置后角度误差小于0.8°将返回一条到位命令或Dir引脚输出高电平)；
	3. 修改无限位碰撞回零完成后不松轴，可以改善向上触发碰撞回零完成后不会掉下来一段（电机松轴导致）；
	4. 加入关键区进出堆栈，优化程序，增加通讯响应速度；
	5. 取消Vm_Limit小屏幕的菜单（少用到，需要的可在上位机中设置）；
