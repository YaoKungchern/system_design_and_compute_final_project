// STM32接线：
	1. STM32F1的PB8接CAN收发器模块的CAN_RX，STM32的PB9接收发器模块的CAN_TX
		STM32F1开发板的3.3V接CAN收发器模块的VCC，STM32F1开发板的Gnd接CAN收发器模块的Gnd
	2. CAN收发器模块型号，如TJA1050芯片模块
	3. CAN收发器模块的CAN_H接闭环的R/A/H，CAN收发器模块的CAN_L接闭环的T/B/L
	4. ZDT_X42_V2闭环需要插入一个ZDT_CAN模块，并把P_Serial设置为CAN1_MAP

// 如果是多机通讯控制，则需要在主机(STM32F1)和最后一个闭环模块上加入一个120欧姆的终端电阻进行匹配。
	（ZDT_CAN模块上有预留一个120欧姆 0603封装的电阻位置）
